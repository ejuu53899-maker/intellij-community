## Integration Dependencies

The trading integrations provided in this repository require external bridge servers to communicate with the trading systems:

### GenX FX Trading System (A6-9V)
- **Bridge Port**: `8000`
- **Source**: `GenX_FX_V4/bridge.py`
- **Configuration**: Requires `JULES_API_KEY_V4` and `GITHUB_TOKEN_PUSH` in MCP settings.

### MQL5-Google-Onedrive
- **Bridge Port**: `8001`
- **Functionality**: Provides cloud synchronization for MetaTrader 5 assets.
- **Trigger**: Manual sync can be triggered via `mql5_sync_trigger`.
